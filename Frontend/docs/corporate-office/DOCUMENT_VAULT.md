# Document Vault

Storage bucket `corporate-private` is private. Documents have classification, versions, checksum, metadata, retention policy and access-event model. No private object is made public as part of a disclosure workflow. Public disclosures must use a separately approved artifact and public metadata.

Use short-lived signed delivery generated by an authorised server route, after checking classification and resource assignment. Validate MIME type, extension, size and file signature before upload. Do not store DSC private keys, PINs, passwords or OTPs.

Corporate evidence is owned by Kravia, not its uploader; offboarding must not delete it.
