# Board Room

Meeting lifecycle: PROPOSED → SCHEDULED → NOTICE PREPARATION → NOTICE ISSUED → AGENDA OPEN → MEETING IN PROGRESS → MEETING CONCLUDED → MINUTES DRAFTING → MINUTES REVIEW → MINUTES FINALISATION → CLOSED.

Notices retain delivery evidence. Agenda items, attendance and minutes versions are structured and separate from personal notes. An approved minutes version can be finalised only via the narrow `finalise_minutes` database function with AAL2 and authorised role. Locked minutes cannot be overwritten; a correction needs a linked amendment record.

This assists governance administration. A CS/Director must confirm notice, quorum, procedure, finalisation and circulation requirements for each actual meeting.
