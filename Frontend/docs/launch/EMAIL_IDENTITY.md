# Corporate email identity

Create functional mailboxes only when the final domain and mail provider are confirmed. Potential roles include contact, corporate, legal, privacy, security, careers and billing.

## Launch checks

- Select a monitored primary public mailbox.
- Publish SPF, DKIM and DMARC only from actual provider instructions.
- Progress DMARC enforcement gradually after all legitimate senders align.
- Test contact confirmation, invitation, password recovery, security and privacy routing.
- Ensure transactional emails use a monitored reply address and do not include private documents or secrets.

Record provider, owner, DNS references and test evidence in the private production inventory.
