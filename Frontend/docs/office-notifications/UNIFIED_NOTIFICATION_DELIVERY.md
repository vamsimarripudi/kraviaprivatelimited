# KRAVIA Office — unified notifications (15 Nov 2026)

## Production integration
- The authenticated Office/Finance shell mounts one global notification hub.
- Server writes to the existing actor-scoped `office_notifications` table with unique event keys.
- Connect message/reply, request/approval, IT-ticket and support-case API handlers deliver on successful, independently authorized mutations.
- An additive database migration handles department-transfer, Vault, leave/Flex-Day and selected Finance record transitions using generic privacy-safe summaries.
- The Office Notification Center retains read/unread/dismiss controls and audit events.
- A short-lived authenticated SSE stream watches the canonical inbox; the browser also has a polling fallback and BroadcastChannel coordination.
- Floating toasts last 7 seconds, 10 seconds for high-priority records, and persist until dismissed for critical records. Three alerts are visible at a time.
- If KRAVIA is in an inactive tab, native browser notifications may be shown only after an explicit permission grant and preference enablement. Cross-tab event keys suppress duplicates.
- Orbit is the default tone, Prism is for approval decisions, Flux is for requests/support, and Beacon is for critical events. The public WAV routes synthesize the original approved note patterns and timing. These are not byte-for-byte copies of the MP3 previews.
- Sound is disabled by default. Quiet hours use Asia/Kolkata time; source retention and IAM are independent of personal alert preferences.
- Never include message bodies, payroll amounts, OTPs, secrets or private document text in native notification summaries. Following a deep link revalidates source authorization.

## Background Web Push limitation
Fully closed-browser/device push delivery is **not enabled** by this release. Web Push requires an installed service worker, a VAPID key pair configured as protected production environment variables, a secure endpoint registry and a push delivery worker. iOS also requires an eligible Home Screen web app. None of those credentials are embedded in this repository. An inactive *open* browser tab may receive native notifications, subject to browser throttling and user permission.
