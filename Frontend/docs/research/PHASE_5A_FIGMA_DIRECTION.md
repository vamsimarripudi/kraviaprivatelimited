## Pre-footer concepts explored in implementation

1. **K-line resolution — selected.** A thin K-derived line crosses into the closing statement, with two concrete actions. It connects visually into the corporate footer without reproducing the logo.
2. **Editorial horizon.** A quiet warm-ivory field with a single enlarged serif statement and a restrained directional line.
3. **Corporate ledger.** A factual identity strip resolves into a closing statement, prioritising disclosure readability over cinematic scale.

The selected code direction is **K-line resolution**: Ideas become systems. Systems become products. It is full-width, reduced-motion safe and does not use an unapproved logo variant.

## Footer concepts explored in implementation

1. **Corporate directory — selected.** Brand statement, multi-column directory, governed corporate-information band, large typographic KRAVIA finish and compact bottom bar.
2. **Monolithic wordmark.** One large typographic closing block with collapsed disclosure rows; rejected because it reduces navigation clarity.
3. **Ledger-first footer.** Corporate facts lead and navigation follows; rejected because it makes the site end like a filing form.

The selected code direction is **Corporate directory**. It preserves the approved logo, keeps factual particulars readable, supports mobile stacking, and does not use fabricated statutory identifiers.
