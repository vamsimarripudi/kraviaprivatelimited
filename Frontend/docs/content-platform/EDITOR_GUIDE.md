# Editor guide

1. Create a record with owner, purpose, structured body and SEO draft.
2. Request the required reviews; do not put evidence in the public body.
3. Resolve changes and inspect the version difference.
4. An authorised publisher approves, schedules or publishes.
5. For corrections, create a revised version and add a correction note where material.
6. Archive instead of deleting published content.

Use the Corporate Fact flow for statutory/company details. Use the Trust flow for privacy, security, DPDP and Responsible AI claims.
